💡 **Satu langkah kecil, satu commit**  
Pilih satu hal paling sederhana yang bisa kamu selesaikan dalam 10‑15 menit. Misalnya, beri tanda “✅” pada file *README* atau tambah komentar kecil di kode yang masih kosong. Setelah selesai, tekan *git commit* dengan pesan singkat:  

```
chore: mulai hari ini, langkah kecil
```

Tidak perlu menunggu “waktunya sempurna”. Setiap detik yang kamu alokasikan kini menjadi jejak yang menumbuhkan kebiasaan.

🔄 **Loop positif**  
Setelah commit pertama, beri dirimu pujian kecil—mungkin sekadar “Berhasil!” atau emoji 🎉. Lihat kembali catatan tadi; mereka bukan untuk menekan, melainkan untuk mengingatkan bahwa kamu punya ruang untuk bergerak.
